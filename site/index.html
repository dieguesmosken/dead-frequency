DEAD FREQUENCY

Uma cidade simulada na zona morta, em primeira pessoa e com cara de PlayStation 1. Escolha uma profissão, ganhe um apartamento no Edifício Sintonia, ouça a Rádio 96.6 e ajude a cidade a funcionar — sozinho ou com até 8 amigos online.

01 O jogo

6 profissões

Entregador (caixas que quebram de verdade), taxista, gari, repositor do mercado, frentista e locutor da Rádio 96.6. Cada uma paga do seu jeito.

Rádio 96.6

Músicas originais de bandas fictícias, sincronizadas pelo relógio: todo mundo ouve o mesmo trecho, na van, no mercado ou no apartamento.

Online com os amigos

Salas por código de 5 letras ou pela lista de salas públicas. Servidor oficial grátis, servidor próprio ou hospede no seu PC.

Cidade e sítio

Cidade gerada com ruas, postos, mercado com interior, delegacia, bombeiros, ônibus 966 e pedestres — e um sítio com bichos, celeiros e estradas de terra.

Física tátil

Pegue e arremesse caixas, empilhe na caçamba, dirija a caminhonete, a moto de entrega ou um caminhão emprestado.

Estilo PS1

Low-poly, neblina densa, noites escuras, orelhões das operadoras paródia (tchau, morto e a rara Telefóbica) e outdoors iluminados.

Verificar o download

Cada versão vem com um SHA256SUMS.txt. No Windows, compare com: certutil -hashfile DeadFrequencyLauncher-windows.exe SHA256. Os arquivos também têm atestado de build do GitHub (prova que saíram do GitHub Actions deste repositório, sem mexida no meio do caminho): gh attestation verify ARQUIVO --repo dieguesmosken/dead-frequency. Veja a política de assinatura de código.

O Windows pode avisar que o arquivo é "desconhecido" (o jogo não tem assinatura paga): clique em Mais informações → Executar assim mesmo. Todas as versões: GitHub Releases · código aberto (GPL-3.0) em github.com/dieguesmosken/dead-frequency.

07 Privacidade

  • Jogando sozinho: o jogo não envia dados da partida para o servidor multiplayer. Quando a opção de procurar atualizações ao abrir está ativada, ele consulta o GitHub para verificar se existe uma versão mais recente. Essa consulta pode transmitir informações técnicas da conexão, como o endereço IP. A verificação pode ser desativada em Opções → Jogo → Procurar atualizações ao abrir.
  • Online: somente quando você entra em uma sala, o jogo se conecta ao servidor escolhido e transmite as informações necessárias para a partida, como nome, cor, profissão, posição dos jogadores e estado de caixas, veículos e outros objetos. O servidor também processa dados necessários para manter a partida, como turno, pedidos, dinheiro do grupo e responsáveis pelos objetos.
  • Dados das salas: enquanto uma sala está ativa, o servidor mantém informações como código, nomes dos jogadores, anfitrião, quantidade de participantes e progresso da partida. Quando todos saem, os dados da sala permanecem por aproximadamente 30 minutos antes de serem apagados automaticamente. O servidor também mantém estatísticas gerais, como salas criadas, entradas, entregas, cargas perdidas, dinheiro ganho, turnos concluídos e recorde de jogadores. A página pública exibe apenas números agregados, sem nomes, códigos de salas ou endereços IP. Não vendemos esses dados nem os utilizamos para publicidade.
  • Segurança e prevenção de abusos: está planejada uma proteção contra tentativas repetidas de acesso não autorizado ao modo desenvolvedor. Quando esse controle estiver implementado, poderá utilizar um identificador pseudonimizado derivado do endereço IP da conexão para limitar tentativas e aplicar bloqueios temporários. Esse identificador não será usado para publicidade ou rastreamento comercial e deverá ser mantido somente pelo período necessário à finalidade de segurança.
  • Infraestrutura: o servidor oficial utiliza a Cloudflare para hospedagem e comunicação em tempo real. A Cloudflare pode processar informações técnicas das conexões, incluindo endereços IP, conforme suas próprias políticas de privacidade e condições de serviço.
  • Hospedar no meu PC: utiliza o Cloudflare Tunnel (cloudflared) para criar um endereço público temporário enquanto a partida está aberta. Os jogadores que entrarem nessa sala se conectarão por meio dessa infraestrutura.
  • Launcher: consulta e baixa as versões do jogo pelo GitHub. A atualização automática é opcional e solicita confirmação na primeira utilização.
  • Este site: não utiliza cookies próprios nem ferramentas de rastreamento publicitário. Ele carrega fontes pelo Google Fonts, consulta a API do GitHub para obter informações sobre versões e acessa as estatísticas públicas do servidor. Esses serviços externos podem processar informações técnicas da conexão, conforme suas próprias políticas.
  • Desinstalar: apague a pasta onde o jogo foi instalado (a escolhida no launcher). As opções e o save ficam em %APPDATA%\Godot\app_userdata\Dead Frequency (Windows) ou ~/.local/share/godot/app_userdata/Dead Frequency (Linux). Apague essa pasta também para remover os dados locais.

Dúvidas ou solicitações relacionadas à privacidade: contato@badwolf3d.com.br.

08 Política de assinatura de código

Os arquivos do jogo e do launcher são compilados pelo GitHub Actions direto do código público deste repositório, com SHA256SUMS.txt e atestado de build em cada versão. A assinatura de código para Windows está em processo de solicitação ao programa gratuito para código aberto da SignPath Foundation.

  • Autores e revisores: Matheus (dieguesmosken). Contribuições de outras pessoas (inclusive código gerado com ajuda de IA) só entram depois da revisão dele.
  • Aprovador das assinaturas: Matheus (dieguesmosken). Cada versão assinada é aprovada manualmente.
  • Commits do mantenedor são assinados (selo Verified no GitHub).
